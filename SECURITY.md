# Security Policy — दैनिक जगत समीक्षा (Dainik Jagat Sameeksha)

## Reporting Security Vulnerabilities

We take the security of Dainik Jagat Sameeksha seriously. If you discover a security vulnerability, please report it privately and responsibly so that we can resolve it promptly.

**Please DO NOT create public GitHub issues or publicly disclose vulnerabilities before they have been resolved.**

### Reporting Channels
- **Security Contact Email:** `jagatsameeksha2014@gmail.com`
- **Chief Editor / Lead Engineer:** अरुण रमाकांत तिवारी (Arun Ramakant Tiwari)
- **Subject Line:** `[SECURITY] Vulnerability Report - Dainik Jagat Sameeksha`

### What to Include in Your Report
To help us triage and investigate efficiently, please include:
1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions or minimal Proof of Concept (PoC) to reproduce the issue.
3. Affected components, routes, or files.
4. Proposed mitigation or patch (if known).

### Response Timeline
- **Initial Response:** Within 48 hours of receipt.
- **Triage & Assessment:** Within 5 business days.
- **Remediation & Patch Deployment:** Critical severity within 7 days; high severity within 14 days.
